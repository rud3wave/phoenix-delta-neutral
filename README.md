# 🔥 Phoenix Delta-Neutral Volume Bot

Дельта-нейтральный бот для фарма объёма на [Phoenix Trade](https://www.phoenix.trade) (Solana perps).

Бот открывает противоположные позиции (LONG + SHORT) на разных кошельках, создавая дельта-нейтральный портфель. Это позволяет фармить объём торгов с минимальным рыночным риском.

> Софт работает только с реферальным кодом автора. Код применяется автоматически при регистрации нового аккаунта — ничего вводить не нужно.

---

## Что делает бот

1. **Группировка кошельков** — кошельки объединяются в группы (например, 2 LONG + 1 SHORT)
2. **Leader-Follower открытие** — одна сторона открывает лимитки, после заполнения вторая сторона бьёт маркетом точно в те же лоты
3. **Удержание** — позиции держатся заданное время
4. **Умное закрытие** — большинство закрывается лимитками (maker fee 0.005%), меньшинство маркетом (taker fee 0.035%)
5. **TG-уведомления** — два сообщения: при открытии и при закрытии с PnL-отчётом

## Установка и запуск

### 1. Установи Node.js

Скачай и установи Node.js **версии 20+** — https://nodejs.org/en/download

Проверь что версия правильная:
```bash
node -v
# v20.x.x или выше
```

### 2. Установи Git (если ещё не установлен)

Скачай и установи — https://gitforwindows.org/ (всё по умолчанию)

### 3. Клонируй репозиторий

Открой терминал (Git Bash или терминал в VS Code) и выполни:
```bash
git clone https://github.com/rud3wave/phoenix-delta-neutral.git
cd phoenix-delta-neutral
```

### 4. Установи зависимости

```bash
npm install
```

### 5. Настрой global.js

Открой `global.js` и заполни:

- `token` — токен от [@BotFather](https://t.me/BotFather) (для TG-уведомлений, можно оставить пустым)
- `chatId` — твой chat ID от [@getmyid_bot](https://t.me/getmyid_bot) (можно оставить 0)
- `ENCRYPTION_PASSWORD` — пароль для шифрования приватных ключей. **НЕ меняй после первого запуска!**

### 6. Настрой settings.ts

Открой `settings.ts` и заполни под себя:

- `TOKENS_TO_TRADE` — какие токены торговать (например `['ETH']`)
- `MARGIN_RANGE` — маржа на позицию в USD, диапазон `[мин, макс]`
- `LEVERAGE_RANGE` — плечо, диапазон `[мин, макс]`
- `GROUP_CONFIGS` — конфигурация групп `[longCount, shortCount]`. **Должно совпадать с количеством кошельков!** Например: 3 кошелька → `[2, 1]`
- `MAX_SPREAD` — максимальный спред для входа (%)
- `HOLD_MINUTES` — время удержания позиций в минутах `[мин, макс]`
- `TRADES_COUNT` — количество циклов `[мин, макс]`

### 7. Добавь приватные ключи

Открой `input_data/privatekeys.txt` и добавь ключи — один на строку.

Поддерживается приватный ключ или мнемоника.

### 8. Добавь прокси

Открой `input_data/proxies.txt` и добавь прокси — один на строку.

Формат: `http://user:pass@ip:port` или `ip:port`

### 9. Запусти

```bash
npm start
```

Бот предложит выбрать режим:
```
Выбери режим:
  1 = Дельта-нейтральная торговля
  2 = Закрыть все позиции
  3 = Проверить балансы
```

---

## Режимы

**Режим 1 — Дельта-нейтральная торговля**
Основной режим. Бот загрузит кошельки, сформирует группы, откроет дельта-нейтральные позиции, подержит и закроет. Повторит заданное количество раз.

**Режим 2 — Закрыть все позиции**
Экстренное закрытие всех открытых позиций и ордеров на всех кошельках.

**Режим 3 — Проверить балансы**
Показывает баланс USDC на каждом кошельке и общий итог.

## Troubleshooting

**npm install падает с ошибкой**
Убедись что Node.js 20+ (`node -v`). Очисти кэш и переустанови:
```bash
rm -rf node_modules package-lock.json
npm install
```

**Ошибка аутентификации Phoenix**
Убедись что приватный ключ правильный. Проверь что кошелёк зарегистрирован на [phoenix.trade](https://www.phoenix.trade). Попробуй перелогиниться на сайте и повтори.

**Транзакции не подтверждаются**
Публичный RPC `api.mainnet-beta.solana.com` имеет лимиты. Для стабильной работы используй приватный RPC (Helius, QuickNode, Triton). Замени `SOLANA_RPC` в `modules/phoenix-service.ts`.

**Спред слишком высокий**
Увеличь `MAX_SPREAD` в `settings.ts` (например, 0.05).

**Кошельки не могут покрыть маржу**
Уменьши `MARGIN_RANGE` в `settings.ts` или пополни балансы кошельков.

**Бот зависает на ожидании лимитки**
Увеличь `LIMIT_FILL_TIMEOUT_MINUTES` в `settings.ts`. Проверь что спред не слишком высокий и на кошельке достаточно USDC.
