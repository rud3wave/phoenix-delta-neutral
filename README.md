# 🔥 Phoenix Delta-Neutral Volume Bot

Дельта-нейтральный бот для фарма объёма на [Phoenix Trade](https://www.phoenix.trade) (Solana perps).

Бот открывает противоположные позиции (LONG + SHORT) на разных кошельках, создавая дельта-нейтральный портфель. Это позволяет фармить объём торгов с минимальным рыночным риском.

> Софт работает только с реферальным кодом автора. Код применяется автоматически при регистрации нового аккаунта — ничего вводить не нужно.

---

## Что делает бот

1. **Группировка кошельков** — кошельки объединяются в группы (например, 3 LONG + 2 SHORT). Кошельки с бóльшим балансом попадают на сторону с меньшим кол-вом кошельков — чтобы риск был равномерный.
2. **Точное выравнивание** — суммарный размер LONG = суммарный размер SHORT (до копейки). Настоящая вилка.
3. **Открытие** — вход только при узком спреде И спокойном mid (фильтр движения цены). Лидер (крупнейшая позиция) ставит лимитки (мейкер), опрос филлов каждые 300мс, перестановка через 2 минуты. После полного заполнения последователь сразу бьёт маркетом (тейкер) точно в фактические лоты лидера — точки входа ног максимально близко.
4. **Удержание** — позиции держатся заданное время.
5. **Закрытие** — лидер закрывается лимитками (мейкер, комиссия ~0.005%) с опросом филлов и перестановкой; затем последователь пробует закрыться лимиткой (мейкер) до 10 секунд, не успел — маркет. Это экономит тейкер-комиссию и ловит спред, риск ограничен окном таймаута.
6. **TG-уведомления** — два сообщения: при открытии и при закрытии с PnL-отчётом.
7. **Забрать награды** — режим 4: собрать реферальные и промо-награды с кошельков.
8. **Депозит на биржу** — режим 5: перевести USDC с кошелька на торговый аккаунт Phoenix.
9. **Вывод средств** — режим 6: перевести доступные USDC с торгового аккаунта Phoenix обратно на кошелёк.
10. **Регистрация аккаунта** — новые кошельки регистрируются автоматически, реферальный код применяется сам.

## Установка и запуск

### 1. Установи Node.js

Скачай и установи Node.js **версии 20+** — https://nodejs.org/en/download

Проверь что версия правильная:
```bash
node -v
# v20.x.x или выше
```

### 2. Установи Git (если ещё не установлен)

Скачай и установи — https://gitforwindows.org/ (всё по умолчанию)

### 3. Создай папку и открой VS Code

Создай папку на рабочем столе (например `phoenix`), открой её в VS Code: **File → Open Folder** → выбери созданную папку.

Открой терминал в VS Code: **Ctrl + `** (обратный апостроф). Убедись что терминал открыт именно в этой папке.

### 4. Клонируй репозиторий

В терминале VS Code выполни:
```bash
git clone https://github.com/rud3wave/phoenix-delta-neutral.git
cd phoenix-delta-neutral
```

### 5. Установи зависимости

```bash
npm install
```

### 6. Настрой global.js

Открой `global.js` и заполни:

- `token` — токен от [@BotFather](https://t.me/BotFather) (для TG-уведомлений, можно оставить пустым)
- `chatId` — твой chat ID от [@getmyid_bot](https://t.me/getmyid_bot) (можно оставить 0)
- `ENCRYPTION_PASSWORD` — пароль для шифрования приватных ключей. **НЕ меняй после первого запуска!**

> В репозитории `global.js` лежит шаблоном без секретов. Заполни его локально и **не коммить** свои значения обратно.

### 7. Настрой settings.ts

Открой `settings.ts` и заполни под себя:

- `ID_FILTER` — какие кошельки участвуют во выбранном режиме. ID равен физическому номеру строки ключа в `privatekeys.txt`; пустые строки и комментарии учитываются в нумерации строк. `>5` выбирает ID 0005 и выше, `<5` — ID 0005 и ниже.

```ts
export const ID_FILTER = []; // Все кошельки
// export const ID_FILTER = ['3', ['10', '13'], '20', '>100'];
```

- `TOKENS_TO_TRADE` — какие токены торговать. Один токен: `['ETH']`. Несколько: `['ETH', 'SOL', 'BTC']` — каждая группа рандомно выберет один.
- `LEVERAGE` — эффективное плечо `[мин, макс]` для каждого токена. Единственная ручка риска: Phoenix на кросс-марже, весь баланс обеспечивает позицию, поэтому notional = баланс × плечо, а ликвидация примерно в `(100 / плечо)%` от входа. Каждый токен из `TOKENS_TO_TRADE` **должен быть в списке!** Не ставь выше максимума биржи (ETH 25x, SOL 25x, BTC 40x).
- `MIN_LIQ_DISTANCE_PERCENT` — минимальная дистанция до ликвидацииации (%). Предохранитель: плечо автоматически режется до `100 / значение` (10 → не выше 10x).
- `SOLANA_RPC_URLS` — список RPC с автопереключением: если узел вернул 429/5xx или недоступен, запрос уходит на следующий. Свой RPC (Helius, QuickNode...) вписывай первым.
- `GROUP_CONFIGS` — конфигурация групп `[longCount, shortCount]`. **Должно совпадать с количеством кошельков!** Например: 5 кошельков → `[[3, 2]]`; 2 кошелька → `[[1, 1]]`
- `MAX_SPREAD` — максимальный спред для входа (%)
- `MAX_MID_DRIFT_PERCENT` + `MID_STABILITY_WINDOW_SEC` — фильтр входа: не открываться, пока mid гуляет больше X% за окно. Бережёт от входа в момент движения цены (ноги входят в близких точках).
- `FILL_POLL_INTERVAL_MS` — как часто проверяются филлы лимиток (мс). Меньше = быстрее вторая нога исполняется вслед за первой (ближе точки ног), но больше RPC-запросов.
- `MAKER_CLOSE_TIMEOUT_SEC` — сколько секунд вторая сторона пробует закрыться лимиткой (мейкер) перед маркетом. Экономия тейкер-комиссии + спред; `0` = всегда сразу маркет.
- `HOLD_MINUTES` — время удержания позиций в минутах `[мин, макс]`. `[0, 0]` = держать бесконечно.
- `TRADES_COUNT` — количество циклов `[мин, макс]`

### 8. Добавь приватные ключи

Открой `input_data/privatekeys.txt` и добавь ключи — один на строку.

Поддерживается приватный ключ или мнемоника.

### 9. Добавь прокси

Открой `input_data/proxies.txt` и добавь прокси — один на строку.

Формат: `http://user:pass@ip:port` или `ip:port`

### 10. Запусти

```bash
npm start
```

Бот предложит выбрать режим:
```
Выбери режим:
  1 = Дельта-нейтральная торговля
  2 = Закрыть все позиции
  3 = Проверить балансы
  4 = Клеймить награды
  5 = Пополнить биржу с кошелька
  6 = Вывод средств
```

---

## Режимы

**Режим 1 — Дельта-нейтральная торговля**
Основной режим. Бот загрузит кошельки, сформирует группы, откроет дельта-нейтральные позиции, подержит и закроет. Повторит заданное количество раз.

**Режим 2 — Закрыть все позиции**
Экстренное закрытие всех открытых позиций и ордеров на всех кошельках.

**Режим 3 — Проверить балансы**
Показывает баланс USDC на каждом кошельке и общий итог.

**Режим 4 — Клеймить награды**
Нужен, чтобы забрать деньги с кошельков: реферальные награды и награды за промо (например [Flight Club](https://x.com/PhoenixTrade/status/2081831859760083422)).

Объём наторговал / по кампании начислили — на сайте это «Claimable», но само на баланс не падает. Режим 4 проходит по всем кошелькам и забирает доступные награды. Без него они просто висят, пока не заклеймишь вручную.

**Режим 5 — Пополнить биржу с кошелька**
Переводит USDC с кошелька на торговый аккаунт Phoenix. Удобно после клейма наград или перед стартом торговли. Если на кошельке почти нет USDC — кошелёк пропускается.

**Режим 6 — Вывод средств**
Выводит все доступные USDC с торгового аккаунта Phoenix обратно на соответствующий кошелёк. Кошельки с открытыми позициями или активными ордерами пропускаются, чтобы не ухудшать маржу.

## Структура проекта

```
phoenix-delta-neutral/
├── main.ts                  # Точка входа
├── settings.ts              # Настройки торговли
├── global.js                # Глобальный конфиг (TG, пароль)
├── input_data/
│   ├── privatekeys.txt      # Приватные ключи (один на строку)
│   └── proxies.txt          # Прокси (один на строку)
├── databases/
│   └── wallets.json         # Зашифрованные ключи (создаётся автоматически)
└── modules/
    ├── allocation.ts        # Математика аллокации notional
    ├── close-strategy.ts    # Закрытие: leader LIMIT → follower MARKET
    ├── controller.ts        # Дельта-нейтральный контроллер
    ├── phoenix-api.ts       # REST API клиент Phoenix
    ├── phoenix-service.ts   # Торговый сервис (ордера, claim, депозит/вывод)
    ├── runtime-control.ts   # Лок запуска и force-close halt
    ├── telegram.ts          # TG-уведомления
    ├── utils.ts             # Утилиты
    ├── wallet.ts            # Кошельки и шифрование
    └── wallet-filter.ts     # Фильтр кошельков по ID
```

## Troubleshooting

**npm install падает с ошибкой**
Убедись что Node.js 20+ (`node -v`). Очисти кэш и переустанови:
```bash
rm -rf node_modules package-lock.json
npm install
```
